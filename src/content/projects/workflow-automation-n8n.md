## Overview

Built and self-hosted an n8n automation server (Docker + Cloudflare + HTTPS) to automate data workflows and AI-assisted reporting (July 2025).

## Approach

- Integrated OpenAI and Gemini APIs to automatically interpret financial, operational, and monitoring data and generate natural language summaries
- Used webhooks and email parsing to trigger workflows on incoming data
- Applied prompt engineering to build real-time decision support flows
