## Overview

An ongoing personal project (started July 2025) building a machine learning system that generates long-term buy signals on a per-ticker basis for portfolio optimization.

## Approach

- Time-series cross-validation to avoid look-ahead bias in backtesting
- Explainable AI metrics to interpret which features drive each signal
- Scoring framework designed to rank tickers for long-term positioning rather than short-term trading
